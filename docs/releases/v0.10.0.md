# lmdv 0.10.0

A parity release across the editor, reader, windows and release packaging.

## Editor

- Entering edit mode puts the caret on the measured block at the reading top
  (or an explicit `--line`), not merely the heading line.
- Mermaid diagrams are reused by source across preview refreshes and invalidated
  when the theme changes.
- The slash menu is anchored to the caret and a replace+insert is one undo step.
- Comments in unknown fence languages and indented code are documented no-ops.
- Block-mode go-to-line accepts `40`, `+N`, `-N`, `N%` and `line:col`.
- The source has scroll-past-end tail space.
- Padding clicks map to the preview line; keyless repeated texts get stable
  identities; the caret uses the preview-height mapping.
- Pasting or dropping an image writes it into the document's `assets/` folder and
  inserts the Markdown link. Pasted documents ask **Save as** first.
- `Ctrl+D` selects the next occurrence. Full multi-cursor remains a Rune gap.

## Reader, links and export

- The keys overlay holds window chords but lets the guide body page with
  PageUp/PageDown/Home/End/arrows.
- The viewer block menu has **Find in document**.
- `Ctrl+C` on an article selection puts Word-friendly HTML and the selected text
  on the clipboard; `Ctrl+Shift+C` still copies the whole document.
- Export uses one stricter parent-folder rule for HTML, DOCX and PDF: the parent
  must exist; folders are never created.
- The table preview has the full key-instruction label, `aria-keyshortcuts` and
  sortable-header descriptions.
- The outline filter has a keyboard cursor: ↑/↓, Enter to the cursor, Esc/clear.
- `<area>` hit boxes, inline SVG groups and area-link presses render; the
  right-click copy-link menu remains OI-195.
- SVG image files can be copied/saved through the public SVG rasterizer.

## Windows, tabs and state

- Each tab keeps its own sticky notice and rendered scheme; notices survive
  switches and tab transfer, and a failed background load stays on its tab.
- Dead recents are pruned on the display clock while the start page is shown.
- The saved check in the tab and the error-card/version paths are now tested.

## Site, identity and signing

- A static project site is published at
  <https://leandromarceddu.github.io/lmdv-rs/> with sepia screenshots, platform
  downloads and latest-release asset links. No analytics, no app webview.
- AppStream uses the metainfo-only rDNS id `io.github.leandromarceddu.lmdv` and a
  homepage; validation is clean.
- Releases now publish `SHA256SUMS.asc`, signed by a dedicated Ed25519 release
  key. Public key: `packaging/lmdv-release-key.asc`, fingerprint
  `DD029B151E6A78B4D2357B17FEFE77EDE1F2E862` (expires 2028-11-24).
- The per-user installer writes a localized `~/Templates` Markdown template
  (S-08), and the installer fallback icon is current.

## Fixes

- A folded sidebar peek now draws the real file tree instead of the empty
  placeholder.
- The full Help guide pages again from the keyboard.
- The project-site screenshots are sepia and cache-busted.

## Assets

- Linux: `lmdv-0.10.0-x86_64.AppImage` and raw `lmdv-0.10.0-x86_64`.
- Windows: `lmdv-0.10.0-installer.exe` and raw
  `lmdv-0.10.0-windows-x86_64.exe`.
- `SHA256SUMS`, `SHA256SUMS.asc` and `lmdv-release-key.asc`.

Verify with:

```bash
gpg --import lmdv-release-key.asc
gpg --verify SHA256SUMS.asc SHA256SUMS
sha256sum -c SHA256SUMS --ignore-missing
```
