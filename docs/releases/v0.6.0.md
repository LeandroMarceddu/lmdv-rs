# lmdv 0.6.0

A links-and-drops release, with the reader and export work that landed after
0.5.5.

## Wiki-style links

- `[text](other)` resolves the way the original does: the spelling itself when
  it is a file, then the spelling with each Markdown extension, then
  `index`/`README`/`readme` inside it. `[x](nested/deeper)` opens
  `deeper.md`; `[x](folder/)` opens its README.
- Resolution runs on a worker. The `#section` survives the lookup, and a
  delayed answer is dropped if the tab or document changed while it ran.

## Link-click placement

- Plain click opens in front, **Ctrl+click** opens a background tab,
  **Ctrl+Shift+click** a foreground tab, **Shift+click** a new window, and a
  **middle click** a background tab.
- The app's tab-per-document model means a plain click opens a foreground tab
  rather than replacing the current tab's document; that is recorded as the
  L-11 substitute.

## Drag and drop

- Dragging Markdown files over the window shows a “Drop to open” card. Dropping
  opens one tab per file: the first in front, the rest behind.
- Dropping on the tab strip inserts the files at that position.
- Non-Markdown files are refused with a notice.
- X11 and Windows. Wayland (winit 0.30) reports no external file drags, so the
  card and the drop are unavailable there.

## Reader and preview, since 0.5.5

- Find and line highlights paint over inline formulas and pictures (Rune patch
  0004); formula TeX, link destinations, front matter and generated TOC labels
  map to their drawn text.
- Table preview zoom (buttons, `1`, Ctrl+wheel, 0.5–2), clickable cells and task
  glyphs; a table wider than the reading column scrolls inside it.
- Footnote jumps glide and land like heading jumps.
- Panes auto-fold and peek over the text; Ctrl+wheel changes panel or reader
  size; the palette folds the full NFKD table and reads real recents.

## Export, since 0.5.5

- DOCX: a real Word `TOC` field, deflate compression (about 45% smaller), SVG
  rasterization, and quoted-list colours.
- PDF: PDF/UA-1, a localized title fallback, alt text, and short code/tables
  kept together across pages.
- Exports flush the editor and parse the exact snapshot; the exporting tab is
  pinned; an ignored large-document benchmark guards performance.

## File safety, since 0.5.5

- Cross-window renames, draft protection for newer-schema files, an inotify
  overflow notice, and portable roots checked for write access before use.

## Parity audit

- Every one of the 342 spec rows is now classified: **169 done, 52 accepted
  substitutes, 90 partial, 13 missing, 18 n/a**. The generated checklist
  reflects the audit, and `docs/PARITY_AUDIT.md` lists the P0 gaps.

## Known gaps

- Image drop into `assets/`, drag-to-scroll, and the remaining P0 partials.
- The Rune bump is a scheduled port (`docs/RUNE_DELTA_2026-11-20.md`), not a
  drop-in.
- Windows remains compile-checked, not runtime-supported.

## Under the hood

- Four Rune patches (inline objects and labels, close veto, accessible inline
  objects, highlights over inline images).
- Six locales at 622 keys; full workspace gate green.
