# lmdv 0.7.0

A parity release across the start page, editor, links and reading.

## Start page and notices

- The start page now has the full set: app mark, “No document open”, the lead
  line, **Open a file…**, **Paste from clipboard**, recent files with **Clear**,
  the three tips, the version, and the F1/? hint.
- Recent files open in the background on a middle click, and ages read
  “just now / 12 min / 3 h / yesterday / date”.
- Notices carry a kind — info, success, warning or error — with the matching
  icon and colour, and are announced through a live region (`status` for
  non-errors, `alert` for errors); a repeated message is announced again.
- The `?` overlay is grouped into Reading / App / Editing / Tabs with localized
  key caps (`Strg`, `Umschalt`, `Leertaste`, `Bild↓`).

## Links

- In-page anchors land 24 pt below the top, plus the measured height of a
  stuck table header; percent-encoded ids resolve, and a missing target is
  silent.
- `tel:` opens its handler; unknown schemes do nothing; script/file schemes
  stay refused.
- A link to another file never opens as text: **Open** for documents, media,
  archives and web files, **Show in folder** for everything else (scripts are
  only revealed).
- A missing target shows “Not found: …” instead of an error tab.
- A pasted document’s relative links offer **Save as…**.
- Network paths are refused unless they belong to the document’s own share.
- Copy works for every code block — top level, nested, duplicated, HTML
  `<pre>`, footnotes — and image sources drop the query while keeping the
  fragment.

## Editor

- The live preview renders 200 ms after the last keystroke; a failed parse
  keeps the last good preview and shows a dismissible error notice.
- Leaving edit mode with unsaved changes asks **Discard** / **Cancel**;
  Discard reloads the saved text and drops the draft.
- The format bar recognizes Setext headings for its active level.

## Reading and windows

- Article padding follows the width: 48/32/96, then 20 side, then 14 side and
  24 top on the narrowest panes.
- F5/Ctrl+R does nothing on a dirty edit buffer or pasted text; a clean file
  reloads in place.
- An mtime-only touch updates the baseline silently; only different text
  reloads.
- A watcher rename shows “Renamed to …”, rekeys everything and re-highlights
  the tree row.
- The outline scrolls its active heading into view.
- A cold-start burst of launches stays in one window, own file first, in order.
- The window opens at 1200×860 with a 480×480 minimum, centred when the session
  does not place it.

## Tabs, since 0.6.0

- Pasted tabs show a clipboard glyph; a save shows a check in the tab for
  1.4 s and announces “Saved”.
- Delete/Backspace closes a focused tab through the normal dirty prompt.
- A background open no longer consumes a front start page.
- Reordering has tests, Esc cancels, and an export pins the strip.

## Parity audit

- Every one of the 342 spec rows is classified: **200 done, 52 accepted
  substitutes, 61 partial, 11 missing, 18 n/a**. Eighteen P0 gaps remain, all
  partial and listed in `docs/PARITY_AUDIT.md`.

## Known gaps

- The Insert and Tools menus on the format bar, the notice bar’s top-centre
  position, dead-recents pruning at display time.
- rune-kit gaps: pane grip labels, a flexible toolbar slot, per-name tab
  widths, a Saved tab status, configurable drag slop, IME composing state
  (OI-190).
- The Rune bump is a scheduled port (`docs/RUNE_DELTA_2026-11-20.md`), not a
  drop-in; Windows remains compile-checked, not runtime-supported.
