# lmdv 0.5.5

A file-safety and accessibility release.

## One document per file

- Opening the same file through a symlink, a hard link or another spelling now
  merges into the document that is already open instead of creating a second
  one. Tabs keep their strip place, reading position and Back/Forward history,
  and other windows join automatically.
- Save As defaults to the file's own folder, the file browser's folder for
  pasted text, or the platform Documents folder. A pasted tab's Back/Forward
  places are renamed to the new file, its draft is dropped, and the document
  matches exactly what was written.
- Save As detects a target that is already open: unsaved changes in any window
  refuse the save with a warning, while a clean duplicate tab is closed so one
  document remains.
- Crash drafts of deleted or unreadable files are offered again. Restoring one
  produces a normal dirty buffer, and `Ctrl+S` reaches **Save again**.

## Spellcheck on Linux

- New Hunspell-compatible engine in `lmdv-edit` (Spellbook, pure Rust, no C
  dependency). Dictionaries are read from the app's `dictionaries` folder,
  `~/.local/share/hunspell`, `/usr/share/hunspell` and `/usr/share/myspell`.
- The interface language selects the dictionary (region, then base language);
  English is used only when nothing matches.
- Misspellings are underlined in both the single-field and block editors,
  checked on a 300 ms worker debounce. Block mode checks only the visible rows.
- The Settings switch appears only while a dictionary is available, and turning
  it off survives a restart.

## Accessible math

- Screen readers now hear `Math: E = mc^2` instead of the U+FFFC object marker,
  through a third Rune patch (`0003-a11y-inline-object`). Inline pictures speak
  their alt text the same way; text navigation and character lengths stay
  consistent with what is read.
- The `--tree` accessibility dump proves it on the math fixture, and a renderer
  regression test walks the real accessibility tree.

## Startup, large files, notices

- Corrupt, oversized or newer-version state files are reported once instead of
  silently reset, and a file written by a newer lmdv is never overwritten.
- Portable mode falls back to the standard XDG folders when its data folder
  cannot be created, with a notice.
- Documents over 8 MiB open in the reader with a warning; `Ctrl+E` still edits.
- The document watcher's setup error is shown once instead of being recorded
  and forgotten.

## Behavior note

- Switching documents keeps each tab's edits, undo history and draft, so no
  discard prompt appears. Closing a tab, a window or the app still asks
  **Save / Don't save / Cancel**, and an in-flight save defers the close until
  it finishes. This is the accepted E-14 substitute, recorded in
  `docs/FEATURE_PARITY.md`.

## Under the hood

- Rune patch set is now 0001 (inline objects + labels), 0002 (close veto) and
  0003 (accessible inline objects); the patch proof tests pass.
- Six locales at 608 keys.
- Full workspace gate green: fmt, check, tests and clippy on Linux; compile
  check on Windows.

## Known gaps

- No right-click spelling suggestions yet; the engine's `suggest` is ready for
  an app-drawn menu (OI-174).
- PDF papercuts (local date, file-selecting “Show in folder”, Print temp
  cleanup) are held for a later release (OI-104).
- Windows remains compile-checked, not runtime-supported (OI-155).
