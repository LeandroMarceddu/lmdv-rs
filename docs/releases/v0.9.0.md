# lmdv 0.9.0

A parity pass across the editor, PDF/print, links, reading and the window
chrome, plus the table-overflow fix.

## Editor

- The editor surface fades in on enter (paint-only, switched off under Reduce
  Motion), and Ctrl+E twice returns to the same reading view: tree, roles,
  anchor, focus and scroll.
- Source/preview sync now maps exact per-line visual geometry using the field’s
  own font, spans and width, in the single field and inside block mode. Every
  table header that can stick is measured, the front matter interpolates as its
  own anchor, and the section-line reserve comes from measured layout.
- This also fixed an inert table-header lookup: the editor cover and the
  reader’s heading clearance were reading a path that never matched.

## PDF and print

- PDF headers and start-page dates use the user’s local calendar day, not UTC.
- **Show in folder** now selects the file: `FileManager1.ShowItems` on Linux
  (folder fallback when no file manager answers), `explorer /select,` on
  Windows, `open -R` on macOS. A missing file reveals its folder.
- `Print…` temporaries are removed after a 30 s grace, or immediately when the
  viewer cannot start. A user-exported file is never removed.
- The “Use the print dialog” failure path and the busy-print refusal are
  tested.

## Links, media and the lightbox

- A link to an image file now opens the full-window preview; a broken image
  falls back to the honest “not a Markdown document” notice.
- Relative paths are percent-decoded (one layer, safe/lossy), including linked
  images.
- Inline images without alt fall back to their source.
- Network/UNC `srcset` candidates are dropped at parse instead of reaching the
  resolver.
- Safe `<map>`/`<area>`/`<svg>` and normalized `xlink:href` are parsed; their
  drawing/hit-testing and a link context menu remain OI-195.
- Block media hints reveal on hover/focus and clip with the picture; inline
  picture hover needs OI-182. Diagrams still need the `rune-mermaid` serializer
  (OI-181); SVG image copy/save needs OI-196.

## Reading and outline

- Find prefill trims, keeps the first line, caps at 100 chars, handles an empty
  selection as an empty query, and only takes article selections.
- The outline filter has pinned 7/8-threshold, empty-state, per-tab, Esc and
  clear-button behavior. A keyboard cursor is OI-198.
- `--line` and footnote jumps reserve the section line (24 + 30 pt) except
  under a measured stuck table header; a leading front-matter line targets the
  card. Footnote backlinks land at exactly 54 pt.

## Tabs, windows and help

- Background opens insert after the last background tab and queue; any tab
  coming forward resets the queue.
- Ctrl+W during a tab drag cancels the drag first; a second press closes.
- New windows chain a 32 pt cascade for 3 s, inherit maximized/minimized state,
  and restart at the display edge. Rune has no work-area API; Wayland lets the
  compositor place.
- The tree traversal has full arrow/Home/End/Enter/Space coverage; fixed Down
  from an unfocused tree skipping the first row.
- The toolbar has a visible Pin button; the window title is
  `“name” — lmdv` with a leading `• ` when dirty.
- Notices have a sticky class: document-open failures survive refreshes and are
  cleared by a document change, save or dismiss.
- The full Help dialog has an About row with the app version, **Repository** and
  **License (MIT)**, localized in six languages. The repository is public and
  the MIT `LICENSE` is in the tree.

## Tables

- Long unbreakable tokens (especially code spans) no longer draw through the
  cell/table border. Columns keep at least their longest word, measured in its
  own face, unbounded above; a table whose floors do not fit grows and scrolls
  horizontally. Ordinary tables are unchanged.
