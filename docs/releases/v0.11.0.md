# lmdv 0.11.0

A runtime upgrade release: lmdv moves to a much newer Rune, retires the local
close-veto patch, and keeps the app's behavior and UI unchanged.

## Rune

- The vendored Rune workspace moves from `cca5df6` (2026-11-17) to
  `f4ec14e` (2026-11-25), 927 commits later.
- Rune now ships the unsaved-close deferral itself
  (`App::on_close_request -> CloseResponse`), so patch 0002 and its test are
  gone. The Save / Don't save / Cancel dialog is unchanged.
- Patches 0001 (inline math images), 0003 (accessible formula labels), 0004
  (highlights over inline images) and 0005 (Mermaid SVG) are re-ported to the
  new `rune-text`, `a11y` and `rune-mermaid` layout.
- The vendor set grows the `naga`, `sctk-adwaita` and
  `accesskit_atspi_common` patches, repeated in the root workspace.

## What the newer Rune brings

- Faster link, pill and decoration hit-testing on large documents; spans and
  glyph runs are no longer limited to 65,535.
- Linux: non-blocking desktop portal at launch, a CPU-drawn first frame that
  hands over to the GPU, Vulkan ICD and adapter/device-loss fallback,
  layer-shell IME/keys/repeat, native file drops, activation tokens, and
  reduced-motion/double-click settings from the desktop portal.
- Windows: correct posted and dead keys, AltGr, touch titlebar drag, DPI and
  UIA focus fixes, DX12/DirectComposition fallback and vblank pacing.
- Images decode on task threads, with scaled decode, intrinsic sizing and
  atlas residency fixes.
- New text APIs used by the re-ported patches: inline child boxes, key
  preview, IME composing state, runtime font registration and SVG path
  shapes.

## Behavior

- No user-facing feature is removed. The reading and editing surfaces are
  unchanged; the close prompt still appears for dirty documents.
- Code blocks keep their 6 pt corners: Rune's new default matches the radius
  the old renderer hard-coded.
- Release headless flags (`--snap`, `--tree`, `--script`) are unchanged.

## Assets

- Linux: `lmdv-0.11.0-x86_64.AppImage` and raw `lmdv-0.11.0-x86_64`.
- Windows: `lmdv-0.11.0-installer.exe` and raw
  `lmdv-0.11.0-windows-x86_64.exe`.
- `SHA256SUMS`, `SHA256SUMS.asc` and `lmdv-release-key.asc`.

Verify with:

```bash
gpg --import lmdv-release-key.asc
gpg --verify SHA256SUMS.asc SHA256SUMS
sha256sum -c SHA256SUMS --ignore-missing
```

## Known gaps

- Seven P0 rows remain partial (T-01, T-03, O-14, C-01, L-11, D-04, I-10);
  the bump makes C-01 and O-14's Alt+arrows app-side work and leaves kit and
  multi-cursor gaps.
- The Windows runtime still needs the manual checklist in OI-155.
- Authenticode/AppImage signing and reproducible builds are still pending.

## Under the hood

- Full workspace gate green before tagging; vendor patch tests (inline image
  layout/scene, a11y, Mermaid SVG) green.
- No Rune pin change after tagging; OI-189 records the re-port.
